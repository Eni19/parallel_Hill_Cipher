Capítulo 1 • O Problema

Por que inventaram a Cifra de Hill?

Durante séculos, as pessoas usavam cifras como a Cifra de César: trocavam cada letra individualmente por outra fixa (exemplo: todo A virava D).

❌ O Defeito das Cifras Antigas

Em português ou inglês, a letra 'A' e a letra 'E' aparecem o tempo todo. Se você sempre troca a letra 'A' por 'X', um espião só precisa contar qual letra mais aparece no texto cifrado e descobre sua mensagem em minutos! Isso se chama análise de frequência.

💡 A Solução de Lester S. Hill (1929)

Em 1929, o matemático Lester Hill teve uma ideia genial: "E se nós não trocássemos letra por letra, mas sim blocos de letras juntos (pares ou trios de letras) usando matemática?"

Com a Cifra de Hill, a mesma letra A pode virar X na primeira palavra e virar M na segunda palavra, porque o resultado depende das letras vizinhas dela no bloco! A análise de frequência simples fica completamente inútil.

Capítulo 5 • O Módulo

Passo 4: O Relógio de 26 Horas (mod 26)

Quando multiplicamos os números, o resultado pode dar um número grande, como 67. Mas o nosso alfabeto só tem letras de 0 a 25! O que fazemos?

26

Aritmética Modular: O Alfabeto dá a volta como um Relógio!

Imagine um relógio com 26 horas (de 0 a 25). Quando você passa do 25, você volta para o 0 (A).
Fazer 67 mod 26 é simplesmente pegar o resto da divisão inteira de 67 por 26:
67 = 2 × 26 + 15 &implies; Resto = 15 (que corresponde à letra 'P'!).

Como Desfazer a Mistura: A Chave Inversa no Código C

Para decifrar o texto, precisamos da matriz inversa $K^{-1}$ (a receita que desfaz a mistura):
K⁻¹ = (1 / det(K)) × adj(K) (mod 26)

Mas em C não podemos fazer divisão fracionária para números que devem ser inteiros mod 26. Olhe o que o autor do Gist (tanayseven/9491684) faz na função Mat_add_num_till_divisible:

trecho de tanayseven_hill_cipher.c Função Mat_add_num_till_divisible
// Soma 26 repetidamente a cada elemento da adjunta até que ele seja exatamente divisível pelo det! void Mat_add_num_till_divisible(Matrix mat, float num, float divisor) { int row_iter, col_iter; for (row_iter = 0; row_iter < mat.rows; ++row_iter) { for (col_iter = 0; col_iter < mat.columns; ++col_iter) { while ((int)Mat_get_element(mat, row_iter, col_iter) % (int)divisor) Mat_set_element(mat, row_iter, col_iter, Mat_get_element(mat, row_iter, col_iter) + num); } } }
Como somar 26 é congruente a 0 mod 26 (26 ≡ 0 mod 26), somar 26 repetidamente não altera o valor modular da matriz! Mas garante que a divisão inteira por det seja 100% exata em C, sem casas decimais!

Por que a Cifra de Hill é Perfeita para Paralelizar em PCD?

Aqui está o ponto central do trabalho do seu grupo na disciplina de Programação Concorrente e Distribuída:
Na Cifra de Hill, o Bloco 1 NÃO precisa do Bloco 2 para ser cifrado. Cada bloco de letras é 100% independente dos outros!

🐢 Versão Sequencial (O Gist de Tanayseven)

Cifra o Bloco 1 → depois o Bloco 2 → depois o Bloco 3... até o Bloco 1.000.000.
Se você tiver um texto gigante, 1 núcleo do processador fica sobrecarregado enquanto os outros núcleos ficam dormindo!

⚡ Versão Concorrente (Seu Projeto de PCD!)

Se você tem 4 núcleos (threads):
• Thread 0 cifra os blocos 1 a 250.000
• Thread 1 cifra os blocos 250.001 a 500.000
• Thread 2 cifra os blocos 500.001 a 750.000
• Thread 3 cifra os blocos 750.001 a 1.000.000
O tempo de execução cai quase 4 vezes!
